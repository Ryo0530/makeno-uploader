結論: 過去データから「次に出る数字」は予想できません (どの予想法も適当に選んだ場合と差がありませんでした)。一方で、 「他の人が選びやすい数字」は当せん口数のデータからはっきり読み取れました。 人と数字がかぶらないように買えば、当たったときに山分けされにくく、受け取れる額の期待値が上がります。

4. 人気の数字 (人とかぶる数字)

3〜5等の当せん口数は「当せん番号に近い数字を買った人」の数です。販売数のトレンドを取り除いて比べると、 人気の数字が出た回は当せん者が多く、不人気の数字が出た回は少なくなります。これを数字ごとに推定しました (赤 = 選ぶ人が多い / 青 = 選ぶ人が少ない)。

人気 (山分けされやすい)不人気 (山分けされにくい)

人気: 12, 11, 8, 7, 3, 6, 5 ／ 不人気: 43, 40, 34, 41, 20, 35, 42
この推定が本物の傾向を捉えているかを確かめるため、 前半のデータで推定して後半の当せん口数を予測すると、相関係数は約 0.79 でした (キャリーオーバーの無い回で評価)。はっきりした予測力があり、人気の傾向は本物と言えます。

データについて

当せん番号・口数・金額は、GitHubで公開されている独立した3つのデータセット (Wantarot/loto6_analyzer の loto6_history.csv、照合用に nodvex/loto6-analyzer と raewonkimdev-eng/kaiun-loto-data) から取得し、全2157回の本数字・ボーナス数字・抽せん日が一致することを確認しています。 正式な当せん番号は宝くじ公式サイトで確認してください。python3 update_data.py で最新データに更新できます。
