# ロト6 過去データ分析・予想システム（監査役つき）

ロト6（1〜43から6個、ボーナス数字1個、1口200円）用です。仕組みは `loto7/` と同じで、ゲームのルールに合わせて数字の範囲・等級・確率を変えています。
Python 3.9以降の標準ライブラリだけで動きます。

```bash
cd loto6
python3 update_data.py         # 当せんデータを取得（3つのデータセットで照合）→ data/loto6.csv
python3 predict.py             # 次回の予想 + 台帳への記録 + 監査 → audit_report.html
python3 predict.py --show all  # 9つの予想法すべての買い目を表示
python3 auditor.py             # 監査だけやり直す（抽せん後に事前予想の成績を見るとき）
python3 analyze.py             # 過去データの分析 → report.html
```

## 等級と確率（1口あたり）

| 等級 | 条件 | 確率 |
|---|---|---|
| 1等 | 本数字6個一致 | 1/6,096,454 |
| 2等 | 本数字5個 + ボーナス数字 | 1/1,016,076 |
| 3等 | 本数字5個 | 1/28,224 |
| 4等 | 本数字4個 | 1/610 |
| 5等 | 本数字3個 | 1/39 |

## わかったこと（第2157回時点）

| 分析 | 結果 |
|---|---|
| 数字ごとの出現回数の偏り | なし（カイ二乗検定 p=0.91） |
| 8つの予想法（ホット・コールド・マルコフ連鎖など） | 第121回以降の2037回で、どれも完全ランダムと差なし |
| **人気の数字（他の人がよく選ぶ数字）** | **はっきりある**（前半データで推定し、後半を予測すると相関 約0.79） |
| 還元率 | 約45%（キャリーオーバーがある回 約49%、ない回 約42%） |

- 人気: 12, 11, 8, 7, 3, 6, 5 など小さい数字
- 不人気: 43, 40, 34, 41, 20, 35, 42 など大きい数字

## データの出どころ

公式サイトにはこの環境から自動でアクセスできないため、GitHubで公開されている独立した3つのデータセットを取得しています。
取得のたびに、全回の本数字・ボーナス数字・抽せん日が一致することを確認しています。

- [Wantarot/loto6_analyzer](https://github.com/Wantarot/loto6_analyzer) `data/loto6_history.csv`（当せん口数・金額・キャリーオーバーを含む）
- [nodvex/loto6-analyzer](https://github.com/nodvex/loto6-analyzer) `data/loto6.json`（照合用）
- [raewonkimdev-eng/kaiun-loto-data](https://github.com/raewonkimdev-eng/kaiun-loto-data) `input/loto6.csv`（照合用）

正式な当せん番号は宝くじ公式サイトで確認してください。
