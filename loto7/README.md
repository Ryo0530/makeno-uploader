# ロト7 過去データ分析ツール

ロト7の全当せんデータ（第1回〜）を統計的に分析し、「人とかぶりにくい」買い目を作るツールです。
Python 3.9以降の標準ライブラリだけで動きます（`pip install` 不要）。

## 使い方

```bash
cd loto7
python3 update_data.py   # 最新の当せんデータを取得 → data/loto7.csv
python3 analyze.py       # 分析して report.html を作成
python3 generate.py      # 買い目を5口作る（-n 10 で10口、--seed 42 で再現可能）
```

`report.html` をブラウザで開くとグラフ付きのレポートが見られます。

## わかったこと（第701回時点）

| 分析 | 結果 |
|---|---|
| 数字ごとの出現回数の偏り | なし（カイ二乗検定 p=0.82） |
| ホット数字・コールド数字・前回と同じ番号などの予想法 | どれも適当に選んだ場合と差なし |
| 前回の番号との重なり・合計値・奇数と偶数の比 | 理論どおり（抽せんはランダム） |
| **人気の数字（他の人がよく選ぶ数字）** | **はっきりある**（前半データで推定し、後半を予測すると相関 約0.45） |
| 還元率 | 約45%（キャリーオーバーがある回 約48%、ない回 約36%） |

つまり、**当たる確率は上げられないものの、当たったときに山分けされにくくはできます**。

- 人気: 7, 8, 5, 9 など1桁の数字と、23, 27, 28
- 不人気: 20, 21, 32, 34, 37, 16, 19

## 仕組み

- **人気の推定**: 4〜6等の当せん口数は「当せん番号に近い数字を買った人の数」を表します。
  当せん口数を確率で割って販売口数を逆算し、前後10回の中央値との比を「その回の当せん番号の人気度」とします。
  この人気度を、どの数字が出たか（37個）と連番の数で回帰（リッジ回帰）して、数字ごとの人気度を求めています。
- **買い目の生成** (`generate.py`): ランダムに作った20万通りの組合せから、次のような組合せを除外します。
  - 過去の当せん番号
  - 連番が2組以上あるもの
  - 1〜31（誕生日に使われる数字）だけで構成されたもの
  - マークシートの同じ行あたりに固まっているもの
  - 等間隔に並んでいるもの

  残った組合せのうち人気度が低い上位2%から、口同士で重なる数字が2個以下になるように選びます。
- **バックテスト**: 各回について、その回より前のデータだけで7個を選び、本数字との一致数を理論値 49/37 ≒ 1.324個 と比べています。

## データの出どころ

公式サイトにはこの環境から自動でアクセスできないため、GitHubで公開されている独立した2つのデータセットを取得しています。
取得のたびに、全回の本数字とボーナス数字が両方で一致することを確認しています。

- [Joker7822/LOTO7_AI_AGENT](https://github.com/Joker7822/LOTO7_AI_AGENT) `loto7.csv`（当せん口数・金額・キャリーオーバーを含む）
- [ogachan111/loto7](https://github.com/ogachan111/loto7) `data.json`（照合用）

正式な当せん番号は宝くじ公式サイトで確認してください。

> 宝くじは長く買い続けるほど損をする仕組みです（還元率は50%未満）。楽しめる範囲で。
