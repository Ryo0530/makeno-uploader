4. 人気の数字 (人とかぶる数字)

4〜6等の当せん口数は「当せん番号に近い数字を買った人」の数です。販売数のトレンドを取り除いて比べると、 人気の数字が出た回は当せん者が多く、不人気の数字が出た回は少なくなります。これを数字ごとに推定しました (赤 = 選ぶ人が多い / 青 = 選ぶ人が少ない)。

人気 (山分けされやすい)不人気 (山分けされにくい)

人気: 7, 8, 5, 9, 23, 27, 28 ／ 不人気: 20, 21, 37, 32, 16, 19, 34
1桁の数字や「7」が好まれ、20〜21、32以上が避けられる傾向です。この推定は本物の傾向を捉えています。 前半のデータで推定して後半の当せん口数を予測すると、相関係数は約 0.45 (キャリーオーバーの無い回で評価) と、はっきりした予測力がありました。
